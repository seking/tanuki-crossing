# タヌキ横断

タヌキを操作して道路・線路・川を渡り、どこまで進めるかを競うブラウザ用の3Dゲーム。

## 遊び方

`index.html` をブラウザで開く。Three.js と Web フォントを CDN から読み込むため、ネット接続が要る。

| 操作 | スマホ | PC |
|---|---|---|
| 前へ | タップ、上スワイプ | ↑ / W |
| 左右 | 左右スワイプ | ← → / A D |
| 後ろへ | 下スワイプ | ↓ / S |

立ち止まるか後ろへ戻りすぎると、カラスにさらわれる。

## 作り

ビルド不要の1ファイル構成。キャラや車はすべて Three.js の立方体を組み合わせて作り、効果音は Web Audio で鳴らす。ハイスコアとどんぐりはブラウザの localStorage に保存する。
